# Architectural-portfolio-tailwindCSS-project
A repo for a TailwindCSS project as part of my ITonline learning course, I followed a brief for a project and implemented what i have learned throughout the course.

current progress - so far i have completed the navigation, statistics block, and footer - applying : custom theme colours, tailwind utility clases, responsive grid layouts, brutalist border-heavy design patterns.

current progress - milestone 2 is complete with the whole first home/index page complete to match the spec

challenges i faced - one of the biggest challenges was the current projects section- each row contained a project number, title, city and two buttons, different title lengths were causing misalignment when using flexbox so i switched to CSS grid with fixed column widths using tailwinds arbitrary values.

What i'm learning - TailwindCSS fundamentals, responsive grid and flexbox, utility-first design workflow, clean html structuring, building consistent UI sections from a design spec.
